## Что делает

Строит полутоновый растр: превращает изображение в узор из точек/линий заданного размера и угла — эффект печатной графики.

## Параметры

| Параметр          | Тип           | По умолчанию | Описание                                                                          |
| ----------------- | ------------- | ------------ | --------------------------------------------------------------------------------- |
| **Halftone mode** | селект        | `gray`       | Цветовая модель растра: `gray`, `rgb`, `hsv`, `cmyk`.                             |
| **Dot size**      | число/список  | 8            | Размер точки (линии) растра в пикселях. Список — рандомизация из набора значений. |
| **Angle**         | число/список  | 45           | Угол наклона растра в градусах. Список — рандомизация.                            |
| **Dot type**      | селект/список | `circle`     | Форма элемента: `circle`, `line`, `ellipse`, `invert`, `invline`.                 |

## Замечания

- `Dot size` задаёт плотность: меньше точка — выше детализация.
- Типы `invert` / `invline` инвертируют яркость растра.
- Если параметр показан списком, из каждого запуска берётся случайное значение списка.
