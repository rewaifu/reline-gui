## What it does

Converts the colour space of an image.

## Parameters

- **Conversion** (select):
  - `RGB2Gray` — colour to greyscale, Rec.601.
  - `RGB2Gray709` — the same, Rec.709.
  - `RGB2Gray2020` — the same, Rec.2020. (Default)
  - `Gray2RGB` — duplicates the single greyscale channel into three colour ones;
    with the current node set it is rarely useful.
