## Что делает

Меняет размер изображения до заданных ширины/высоты или пропорционально.

## Параметры

| Параметр        | Тип   | По умолчанию | Описание                   |
| --------------- | ----- | ------------ | -------------------------- |
| **Width (px)**  | число | 2000         | Целевая ширина в пикселях. |
| **Height (px)** | число | 2000         | Целевая высота в пикселях. |

## Замечания

- Для апскейла лучше использовать ноду **Upscale** (нейросеть), а Resize оставить для точной подгонки размеров.
- Уменьшение интерполяцией даёт более чистый результат, чем увеличение.
