## Что делает

Записывает обработанные изображения в папку — финальная нода конвейера.

## Параметры

| Параметр           | Тип    | По умолчанию | Описание                                                                      |
| ------------------ | ------ | ------------ | ----------------------------------------------------------------------------- |
| **Path to folder** | текст  | пусто        | Папка назначения. Создаётся при записи, если не существует.                   |
| **Format**         | селект | `png`        | Формат сохранения: `png` (без потерь) или `jpeg` (меньше размер, с потерями). |

## Замечания

- Имена файлов сохраняются исходные; при конфликте файл перезаписывается.
- Для `jpeg` качество берётся из глобальных настроек запуска.
