## Что делает

Читает изображения из папки и подаёт их на вход конвейера. Поддерживает рекурсивный обход вложенных папок и перевод в градации серого.

## Параметры

| Параметр           | Тип     | По умолчанию | Описание                                                                       |
| ------------------ | ------- | ------------ | ------------------------------------------------------------------------------ |
| **Path to folder** | текст   | пусто        | Путь к папке с изображениями. Относительный или абсолютный.                    |
| **Mode**           | селект  | `rgb`        | `rgb` — цветные изображения, `gray` — конвертация в оттенки серого при чтении. |
| **Recursive**      | чекбокс | выкл         | Обходить вложенные папки рекурсивно.                                           |

## Замечания

- Порядок подачи файлов — лексикографический по имени файла; назвать файлы с числовым префиксом (`001_...`, `002_...`), чтобы управлять порядком.
- Если папка недоступна или пуста, нода вернёт ошибку в лог запуска.
- Для распаковки архивов добавьте отдельную ноду **Unarchive** из группы «Препроцесс».
