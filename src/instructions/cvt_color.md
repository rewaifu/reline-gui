## Что делает

Конвертирует цветовое пространство изображения.

## Параметры

| Параметр | Тип    | По умолчанию | Описание                                                            |
| -------- | ------ | ------------ | ------------------------------------------------------------------- |
| **Mode** | селект | `gray`       | Целевое пространство: `gray` — оттенки серого, `rgb`, `hsv`, `lab`. |

## Замечания

- `lab` удобен для последующей резкости/контраста по каналу яркости без сдвига цвета.
- Конвертация в `gray` необратима — ставьте ноду в конце цветовой обработки.
