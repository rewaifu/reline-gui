## Что делает

Записывает обработанные изображения в папку. Всегда стоит последней в пайплайне,
иначе конфиг не валиден.

## Параметры

- **Путь к папке** (текстовое поле) — папка назначения; создаётся при записи, если
  её ещё нет.
- **Формат** (селект) — в каком формате сохранять:
  - `png` — без потерь (по умолчанию).
  - `jpeg` — меньше размер, но с потерями.
- **PSD** (флаг) — после записи собрать для каждого изображения layered-PSD
  в подпапке `psd`: исходный файл становится фоном, обработанный — слоем
  сверху. Выключен — постпроцесса нет.
- **Удалять исходники после PSD** (флаг, виден при включённом PSD) — плоские
  файлы, по которым собрали PSD, удаляются. В папке остаются только `.psd`.
- **Очищать папку перед запуском** (флаг) — перед началом работы папка
  назначения вычищается целиком (препроцессор `cleandir`), чтобы старые файлы
  не смешивались с новыми.

## Замечания

- Имена файлов сохраняются исходные, при совпадении файл перезаписывается.
- Вложенные папки повторяют структуру входа.
- PSD пишет `.psd` в подпапку `psd` рядом с результатом и стыкует обработанное
  с фоном по имени файла: сначала пары с одинаковым именем, потом остатки с
  обеих сторон по порядку имён (`img2` раньше `img10`) — пока не кончатся файлы
  с одной из сторон. Нет пары — файл пропускается, прогон продолжается.
