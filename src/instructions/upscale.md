## Что делает

Увеличивает разрешение изображения нейросетевой моделью апскейла из локального пути.

## Параметры

| Параметр              | Тип     | По умолчанию | Описание                                                                                                       |
| --------------------- | ------- | ------------ | -------------------------------------------------------------------------------------------------------------- |
| **Model path**        | текст   | пусто        | Путь к файлу модели. Чтобы скачать модель по имени, поставьте перед нодой **Download** из группы «Препроцесс». |
| **DType**             | селект  | `F32`        | Точность весов: `F32` — максимум качества, `F16`/`BF16` — быстрее и меньше памяти.                             |
| **Tiler**             | селект  | `exact`      | `exact` — обработка тайлами фиксированного размера, `no_tiling` — всё изображение целиком.                     |
| **Exact tiler size**  | число   | 0            | Размер тайла в пикселях при `exact` (например 512).                                                            |
| **Allow CPU upscale** | чекбокс | выкл         | Разрешить инференс на CPU, если GPU недоступен или не хватает видеопамяти.                                     |
| **Target scale**      | число   | 0            | Целевой множитель увеличения (например 2 или 4). 0 — нативный масштаб модели.                                  |

## Замечания

- Большие тайлы быстрее на GPU, но требуют больше видеопамяти; при OOM уменьшите `Exact tiler size`.
- `F16` обычно неотличим по качеству от `F32` и заметно быстрее.
