## Что делает

Корректирует уровни яркости: переприсваивает диапазон входных яркостей в выходной (аналог Levels).

## Параметры

| Параметр         | Тип          | По умолчанию | Описание                                                                     |
| ---------------- | ------------ | ------------ | ---------------------------------------------------------------------------- |
| **Input range**  | число/список | 0            | Нижняя граница входного диапазона (тени). Значения ниже обрезаются в чёрное. |
| **Gamma**        | число/список | 1.0          | Гамма-кривая: меньше 1 — светлее, больше 1 — темнее.                         |
| **Output range** | число/список | 255          | Верхняя граница выхода (света).                                              |

## Замечания

- Классика: `Input range = 16`, `Gamma = 1.0`, `Output range = 240` — мягкое расширение контраста без клиппинга.
- Работает в каждом канале независимо, если режим не `gray`.
