## Что делает

Повышает резкость изображения простым фильтром.

## Параметры

| Параметр   | Тип   | По умолчанию | Описание                                                         |
| ---------- | ----- | ------------ | ---------------------------------------------------------------- |
| **Amount** | число | 0            | Сила резкости в процентах (например 50 — умеренно, 150 — грубо). |

## Замечания

- Применяйте **после** апскейла: резкость на маленьком изображении усиливает артефакты сжатия.
- Значения выше ~200% почти всегда дают ореолы вокруг контуров.
