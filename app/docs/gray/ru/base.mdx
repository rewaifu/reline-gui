# Основы апскейла ЧБ манги

Выбор подхода зависит от ваших входных данных:
* Для ЧБ сканов без скринтона всё относительно просто — можно использовать либо общие модели для цвета, либо для более резких линий одну из DS-моделей (может иметь пагубный эффект для различных текстур) или `4x_eula_digimanga_MiA_65k`.
* Со сканами же со скринтоном всё обстоит чуть сложнее.

## Для апскейла сканов со скринтоном есть несколько парадигм:

### 1. MangaScale

Самая примитивная по своей сути, ведь нам нужно использовать лишь узел <NodeRef type="upscale" />, но&nbsp;применима она только к исходникам с достаточно хорошо видимым скринтоном.
<br/>Подробнее в <ArticleRef slug="mangascale" />

### 2. Переналожение скринтона
Более комплексный алгоритм, подразумевающий под собой преобразование оригинального скринтона в оттенки серого, с последующим его переналожением.
<br/>Подробнее в <ArticleRef slug="rescreentone" />
