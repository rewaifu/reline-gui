# Апскейл цвета

В скейле цвета все сложности упираются только в выбор модели, а так конфиги почти всегда имеют вид:

1. <NodeRef type="folder_reader" />
2. <NodeRef type="upscale" /> — апскейл выбранной моделью;
3. <NodeRef type="level" /> — убираем шумы скейла, при помощи <code><T k="nodes.level.high-input"/></code> = `253`;
4. <NodeRef type="resize" /> (опционально)
5. <NodeRef type="folder_writer" />

___

# По поводу выбора моделек:

### Просто почистить шум
Если нужно лишь немного убрать шум без увеличения:
* `1x_umzi_digital_decompress_gaterv3_1`

### Вебтуны
Для небольшого апскейла вебтунов хорошо подходят модели:
* `2x_enhancr_da_figsr`
* `2x_enhancr_da_smosr_v1`

### Цветная манга и арты
Для иллюстраций и цветных артов:
* `4x_IllustrationJaNai_V3detail_DAT2_28k_bf16` — лучший вариант, но модель достаточно тяжёлая
* `4x_umzi_digital_art_mosr_l` — вариант полегче
