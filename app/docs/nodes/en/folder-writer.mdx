# Folder writer

<DemoNode type="folder_writer"/>

## What does it do?
Writes processed images to the specified folder.

## Parameters
* <code><T k="nodes.folder-writer.path"/></code> — the path to the folder where the processed files will be saved. If the folder does not exist, it will be created from scratch. For a notebook in Colab the path must start with&nbsp;<code>/content/drive/MyDrive/</code>;
* <code><T k="nodes.folder-writer.format"/></code> — the choice of the output file format.
