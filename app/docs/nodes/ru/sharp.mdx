# Резкость

<DemoNode type="sharp"/>

## Что делает?
Делает линии более резкими для подготовки к обработке при помощи узла <NodeRef type="screentone"/>.

## Для чего это нужно?
Из-за особенностей алгоритма, используемого в узле <NodeRef type="screentone"/>, на краях линий возникает эффект «пил», так как мелкие серые пиксели превращаются в скринтон. Этот узел позволяет сделать контуры полностью чёрными.
<br/>На картинке ниже пример оригинального скана, и наложенного скринтона с предобработкой при помощи узла <NodeRef type="sharp"/> и без.
<DocImage src="/docs/saw.webp" alt="saw pattern" caption="Оригинал vs С резкостью (нет «пил») vs Без резкости (есть «пилы»)" />

<br/>Также большинство моделей для узла <NodeRef type="upscale"/> немного смещают цвета, создавая еле различимый рисунок (яркость 1/255), который запросто правится при помощи узла <NodeRef type="level"/>, либо сразу здесь, в параметре <code><T k="nodes.sharp.high-input"/></code> (почти для всего хватает значения `253`).

## Параметры
* <code><T k="nodes.sharp.low-input"/></code> — усиление тёмных тонов (тёмный темнее);
* <code><T k="nodes.sharp.high-input"/></code> — усиление светлых тонов (светлый светлее);
* <code><T k="nodes.sharp.gamma"/></code> — цветовая гамма (смещение средних тонов);
* <code><T k="nodes.sharp.diapason-white"/></code> — превращает все более светлые цвета в белый;
* <code><T k="nodes.sharp.diapason-black"/></code> — (устарело, рекомендуется отключать, выставив значение -1) всё, что темнее становится чёрным и чуть шире. Раньше нужно было для исправления «пил» на контурах при наложении скринтона, но сейчас с этой задачей прекрасно справляется <code><T k="nodes.sharp.canny"/></code>;
* <code><T k="nodes.sharp.canny"/></code> — включает алгоритм Кэнни для применения резкости на контурах, помогает избавиться от «пил» при переналожении скринтона;
* <code><T k="nodes.sharp.canny-type"/></code> — выбор типа Кэнни:
    * <code><T k="nodes.sharp.canny-type-options.normal"/></code> — (устарело) накладывает чёрную битную линию поверх контуров, делая их жирнее;
    * <code><T k="nodes.sharp.canny-type-options.invert"/></code> — (устарело) накладывает белую битную линию поверх контуров, выжигая их;
    * <code><T k="nodes.sharp.canny-type-options.unsharp"/></code> — магия кучи преобразований с масками, в результате чего выходят резкие линии той же ширины;
