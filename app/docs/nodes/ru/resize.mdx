# Размер

<DemoNode type="resize"/>

## Что делает?
Меняет размер изображения.

## Для чего это нужно?
Большинство сайтов сканлейт-агрегаторов пережимает изображения слишком высокого разрешения (Пример: Mangalib сжимает сканы более ~17000 пикселей по высоте или ~3000 пикселей по ширине), поэтому этот узел удобно использовать для пакетного уменьшения обработанных сканов.

## Лучшие фильтры
Советуем вам самим поэксперементировать с фильтрами и поискать лучшие для себя, но от себя рекомендуем следующие:
- Для ЧБ со скринтоном прекрасно подходит `shamming4`;
- Для цветных изображений одну из разновидностей `dpid`;
- Универсальный вариант для всего остального `mitchell`.

## Параметры
* <code><T k="nodes.resize.filter"/></code> — фильтр для интерполяции:
    * `nearest` — метод интерполяции «ближайшего соседа», из-за особенностей своей работы вывод получается «ступенчатым»;
    * `box` — среднее между «ближайшим соседом» и билинейной интерполяцией (в случае сжатия);
    * `linear` — билинейная интерполяция, результат получается довольно гладким, но сам метод подвержен потере части информации;
    * `dpid` — сложный алгоритм, пытающийся сохранить как можно больше мелких деталей. Прекрасный вариант для цветных изображений, но плохо справляется с полутоновыми узорами;
    * `lanczos` — метод Ланцоша известен своими «ореолами» по краям линий, схожий эффект возникает при выкрученной резкости;
    * `hamming` — интерполяция с окном Хэмминга, немного схожая по своей структуре с Ланцошем, но без «ореолов»;
    * Фильтры с префиксом `i` — сверхбыстрые алгоритмы интерполяции, чуть мягче «ближайшего соседа» но страдают от <a href="https://ru.wikipedia.org/wiki/%D0%9C%D1%83%D0%B0%D1%80%D0%BE%D0%B2%D1%8B%D0%B9_%D1%83%D0%B7%D0%BE%D1%80" target="_blank" rel="noopener noreferrer" className="hover:text-blue-400  underline">муара</a>;
    * Фильтры с префиксом `s` — используется сложный алгоритм, на выходе которого получаются чуть лучшие линии при сильном сжатии;
    * Остальное — разновидности бикубической интерполяции с варьирующейся степенью «резкости» и «размытости».

* <code><T k="nodes.resize.resize-type"/></code> — выбирает метод масштабирования:
    * <code><T k="nodes.resize.resize-type-options.width"/></code> — масштабирует изображение по горизонтали до указанного в <code><T k="nodes.resize.width"/></code> значения с сохранением соотношения сторон;
    * <code><T k="nodes.resize.resize-type-options.height"/></code> — масштабирует изображение по вертикали до указанного в <code><T k="nodes.resize.height"/></code> значения с сохранением соотношения сторон;
    * <code><T k="nodes.resize.resize-type-options.absolute"/></code> — масштабирует изображение до указанных в <code><T k="nodes.resize.width"/></code> и <code><T k="nodes.resize.height"/></code> значений;
    * <code><T k="nodes.resize.resize-type-options.percent"/></code> — масштабирует изображение в указанное в <code><T k="nodes.resize.percent"/></code> число раз;
* <code><T k="nodes.resize.spread"/></code> — включает особый режим для альбомных изображений (например, разворотов в манге). Если ширина скана больше высоты, стандартное значение <code><T k="nodes.resize.width"/></code> игнорируется, и изображение масштабируется по ширине, указанной в <code><T k="nodes.resize.spread-size"/></code>. Работает только при <code><T k="nodes.resize.resize-type"/></code> = <code><T k="nodes.resize.resize-type-options.width"/></code>;
* <code><T k="nodes.resize.spread-size"/></code> — альтернативное значение ширины в пикселях, которое применяется к альбомным изображениям вместо основного при включённом параметре <code><T k="nodes.resize.spread"/></code>.
