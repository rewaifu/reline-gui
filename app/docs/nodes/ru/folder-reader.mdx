# Чтение

<DemoNode type="folder_reader" />

## Что делает?
Как следует из названия — читает изображения из заданной папки.

## Параметры
* <code><T k="nodes.folder-reader.path"/></code> — путь к вашей папке с изображениями для обработки. Для блокнота в Colab путь должен начинаться с `/content/drive/MyDrive/`;
* <code><T k="nodes.folder-reader.mode"/></code> — выбор цветовой палитры входных изображений. При <code><T k="nodes.folder-reader.mode"/></code> = <code><T k="nodes.folder-reader.mode-options.gray"/></code> переводит изображения в ЧБ (без смены цветового пространства);
* <code><T k="nodes.folder-reader.recursive"/></code> — рекурсивный обход папок. Будет считывать файлы во всех подпапках;
* <code><T k="nodes.folder-reader.unarchive"/></code> — распаковывает архивы и читает файлы с них. Работает только в Colab.
