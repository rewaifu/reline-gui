# ЦВ палитра

<DemoNode type="cvt_color"/>

## Что делает?
Переводит изображение из одного цветового пространство в другое.

## Для чего это нужно?
Для изображений в ЧБ не к чему хранить данные о цветах, из-за чего, при переводе в градации серого, файлы уменьшаются в объёме.

## Параметры
* <code><T k="nodes.cvt.cvt-type"/></code> — выбор метода преобразования:
    1. `RGB2Gray`, `RGB2Gray709`, `RGB2Gray2020` — перевод из режима RGB в градации серого. Самый точный `RGB2Gray2020`;
    2. `Gray2RGB` — перевод из градаций серого в RGB.
