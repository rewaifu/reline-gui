# Запись

<DemoNode type="folder_writer"/>

## Что делает?
Записывает обработанные изображения в указанную папку.

## Параметры
* <code><T k="nodes.folder-writer.path"/></code> — путь папке, куда будет сохранены обработанные файлы. Если папки не существует, то она будет создана с нуля. Для блокнота в Colab путь должен начинаться с&nbsp;<code>/content/drive/MyDrive/</code>;
* <code><T k="nodes.folder-writer.format"/></code> — выбор формата выходных файлов.
